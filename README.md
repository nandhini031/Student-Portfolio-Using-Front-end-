# Student-Portfolio-Using-Front-end-
The portfolio effectively presents professional information in a clean and modern interface, improving online presence and demonstrating frontend development and UI design skills
Designed and developed a modern responsive personal portfolio website using HTML and CSS with a professional Navy Blue UI theme. The portfolio showcases personal profile, technical skills, internship experience, projects, certifications, education, and contact information in a visually appealing and structured format. The website includes smooth animations, hover effects, responsive layouts, and a frosted-glass navigation design to provide an elegant user experience across desktop and mobile devices.
The project follows a clean component-based structure using reusable CSS variables for easy customization of colors, fonts, and layouts. The dark navy aesthetic combined with sky-blue accents creates a modern professional appearance suitable for software developers and data analysts.

Key Features

Responsive design compatible with desktop and mobile devices
Fixed frosted-glass navigation bar
Interactive hero section with animated stat cards
Skills and project showcase using card-based layouts
Smooth hover transitions and fade animations
Reusable CSS variable system for theme customization
Professional dark-themed UI with modern typography

Technologies Used
HTML5
CSS3
CSS Grid & Flexbox
Responsive Web Design
Google Fonts
